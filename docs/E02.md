# E02 — Bibliothèque et affectations

Depuis Formations → Catalogue → Interactive resources, créer la ressource puis
« Importer une version ». Renseigner paquet, numéro, licence et provenance ; le
contrôle serveur précède tout stockage. Ouvrir la version, prévisualiser dans
l’origine isolée puis publier avec le rôle coordination.

Dans « Affectations interactives », choisir programme, version publiée, objectif
et règle de complétion. Valider fige cette règle. « Affecter aux réalisations »
crée une activité distincte dans chaque réalisation du programme. Répéter la même
opération retrouve l’usage existant sans doublon. Les sociétés doivent correspondre ;
aucun partage inter-sociétés implicite. Les réalisations existantes ne basculent
jamais vers V2 lors de sa publication.

La version garde octets, empreinte, provenance et licence. Les usages permettent
de voir où la version est affectée ; ils ne sont pas modifiables. L’archivage de la
ressource empêche les nouveaux usages, sans retirer les anciens. Le retrait de
sécurité d’une version bloque ses lectures suivantes, avec motif, et conserve
les traces. La liste des usages est accessible depuis chaque affectation.

Le critère formatif est distinct des déclarations, validations humaines et examens.
Il reste incomplet tant que la projection E04 n’est pas activée. Cet incrément
n’expose pas encore de lecteur participant. Les tests vérifient le formulaire,
l’import, le partage sur deux réalisations, le gel, V2 et l’archivage.
